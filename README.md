# バクテリア・レース 3D

8種の細菌が1本のコースで混走する、ブラウザで遊べる3Dアイテムバトルレースです。
各菌の速さは、粘性なし・粘性あり（0.4% メチルセルロース）・狭小（幅 1.25 µm の流路）の3環境で実測された平均遊泳速度をもとにしています。

## もとになった論文

[Cell-scale confinement reorders bacterial speed rankings](https://www.biorxiv.org/content/10.64898/2026.11.04.764272v1)（bioRxiv）

## 遊び方

`index.html` をブラウザで開くだけで動きます（three.js とフォントを CDN から読み込むため、インターネット接続が必要です）。

| 操作 | キー |
|---|---|
| 左右移動 | ← → / A D |
| アイテムを使う | Space |
| ラッピング切替（*V. fischeri*・*C. insecticola*・*C. jejuni*） | Shift |

スマートフォンでは画面上のボタンで操作できます。

## 内容

- **5つのコース**: マイクロ流体サーキット、腸内クリプト・バレー、土壌ポア・ラビリンス、発光器ナイトラン、熱水噴出孔ラッシュ。粘性なし・粘性あり・狭小の区画が左右にも入り組み、粘性の近道、穴、柵のない縁（場外）があります。
- **アイテム**: グルコース（加速）、ファージ（前の1菌を追尾）、抗生物質5系統（相性あり）、バイオフィルム（防御）。
- **ラッピングモード**: べん毛を菌体に巻きつけ、狭小区画で加速します。

## データとゲーム上の設定について

- 速度は上記論文の動画（Movie S3 “Which bacterium swims fastest?”）に表示された各種・各環境の平均値です。
- 抗生物質の相性は、グラム染色性・外膜の有無・属レベルで知られる自然耐性の傾向をゲーム用に3段階へ単純化したもので、論文のデータではありません。株によって異なり、医療上の判断には使えません。
- コースの形、近道の倍率、ラッピングによる加速、バトル補正（速度 = 32 + 0.2 × 実測）、追い上げ補正はゲーム上の設定です。
